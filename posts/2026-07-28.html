🔥 GitHub 今日热门：AI 看片、蓝牙聊天、还有能炒股的“柯罗诺斯”？

哈喽各位摸鱼工程师、代码诗人、以及正在偷偷刷 GitHub 的加班狗们！欢迎收看今天的“我和我的代码都笑了”栏目。今天是 2026 年 7 月 28 日，GitHub Trending 上又冒出了一堆神仙项目，让我看看——有能聊天的蓝牙、能看视频的 AI、能炒股的 AI、还有能帮你写代码审稿的 AI……总之，AI 今天又赢麻了。

1. **permissionlesstech/bitchat** 🐝

一句话总结：用蓝牙当对讲机，IRC 的魂，没有网也能水群。

点评：这名字太直白了，叫“Bitchat”，让我想起办公室那个天天抱怨“这他妈谁写的代码”的同事。蓝牙 Mesh 聊天，IRC 风格，意思就是——你可以在没有 WiFi 的深山老林里，跟隔壁帐篷的人发 /me 掏出烤串。今日 +2,346 stars，估计都是想跟老板开会时悄悄吐槽的社畜。

2. **amnezia-vpn/amnezia-client** 🛡️

一句话总结：开源 VPN 客户端，让你从“404”变成“200 OK”。

点评：C++ 写的，13k+ stars，今日 +515。老牌 VPN 项目了，桌面移动都支持。这玩意儿的价值在于：当你被公司防火墙气到想砸键盘时，它能让你看到外面的世界——比如看看 GitHub 今天又有什么新轮子。温馨提示：别用它看招聘网站，怕你跳槽。

3. **moeru-ai/airi** 🤖💖
